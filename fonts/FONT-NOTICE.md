# Font notice

Hyper Cards includes `FiraCodeNerdFontMonoShort76-Regular.ttf`.

The font is a modified FiraCode Nerd Font Mono. The Powerline separator glyph at U+E0B1 was vertically shortened to 76% of its original height and centered for use with the supplied Hyper and Starship presets.

The embedded font metadata identifies the base as Fira Code 6.002 with Nerd Fonts 3.0.2.
